# Herramientas de IA

Configuración de las herramientas de asistencia usadas en el proyecto.

La configuración real de **[OpenCode](https://opencode.ai)** vive en la raíz del
repo, en [`.opencode/opencode.json`](../../.opencode/opencode.json) (ubicación que
OpenCode descubre automáticamente). Define los servidores MCP habilitados
(context7 para documentación de librerías, sequential-thinking para razonamiento).

> El **uso de IA está declarado** en el [`../../README.md`](../../README.md) (§14) y la bitácora
> detallada en [`../ai-log.md`](../ai-log.md). Todo el código fue leído, probado y entendido por el autor.
